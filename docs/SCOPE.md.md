# SportHub — Project Scope Document (ฉบับสมบูรณ์)
**Version 5.0 | มิถุนายน 2026**

---

## 1. ภาพรวมโครงการ

SportHub คือแพลตฟอร์ม SaaS ที่เจ้าของระบบเป็นตัวกลาง เปิดให้สนามกีฬาและฟิตเนสทั่วประเทศไทยสมัครเข้ามาใช้งาน แต่ละสนามได้พื้นที่ข้อมูลแยกของตัวเองในระบบ ระบบครอบคลุม 10 Module หลักคือ จองสนามกีฬา สมาชิกฟิตเนส ชำระเงินผ่าน QR PromptPay เช็คอินหลายสาขา Subscription B2B ผ่าน Omise การจัดการสาขา โปรโมชั่นและคูปอง ศูนย์แจ้งเตือน รายงาน และ Analytics

---

## 2. โมเดลธุรกิจ

เจ้าของ SportHub คือผู้ดูแลแพลตฟอร์ม สนามและฟิตเนสสมัครเข้ามาเป็น Tenant จ่ายค่าสมัครรายเดือนผ่าน **Omise Payment Gateway** เงินค่าจองสนามและค่าสมาชิกฟิตเนสโอนตรงจากลูกค้าเข้าบัญชีสนามผ่าน PromptPay SportHub ไม่ได้แตะเงินส่วนนี้ รายได้ของ SportHub มาจากค่า Subscription รายเดือนของสนามที่เก็บผ่าน Omise เท่านั้น

## 3. User Roles

### 3.1 Super Admin (ทีม SportHub)

**สิทธิ์:** จัดการ Tenant ทั้งหมด ดู Dashboard รายได้ Subscription รวม เปิด/ปิด/ระงับบัญชีสนาม จัดการ Trial Period ดูสถิติภาพรวมทั้งระบบ

**ข้อมูลที่เข้าถึงได้:**
- รายชื่อ Tenant ทั้งหมด (ชื่อสนาม ชื่อเจ้าของ เบอร์ติดต่อ อีเมล วันสมัคร แพลนปัจจุบัน สถานะ วันหมด Trial)
- Dashboard รายได้ Subscription รวม (MRR รายเดือน รายปี Churn Rate)
- Log การใช้งานและประวัติ Upgrade/Downgrade ของแต่ละ Tenant
- สถิติภาพรวม (จำนวน Tenant แยกตามสถานะ: Active/Trial/Free/Suspended จำนวนการจองรวม จำนวนสมาชิกรวม)
- รายการชำระ Subscription และรายการค้างชำระ

### 3.2 Venue Owner / Admin (เจ้าของสนาม/ฟิตเนส)

**สิทธิ์:** ตั้งค่าสนามและสาขา จัดการสมาชิก ดู Dashboard รายได้ของตัวเอง ออกรายงาน จัดการโปรโมชั่น ยืนยันสลิปการชำระเงิน กำหนดสิทธิ์ Staff

**ข้อมูลที่เข้าถึงได้:**
- ข้อมูลสนามและสาขาทั้งหมดของตัวเอง
- ข้อมูลสมาชิกทั้งหมดของตัวเอง (เต็ม)
- รายงานรายได้และสถิติทุกด้าน
- สลิปการชำระเงินทั้งหมด
- ประวัติเช็คอินทุกสาขา
- ข้อมูลพนักงาน (Staff) ทั้งหมด

### 3.3 Staff (พนักงานหน้าเคาน์เตอร์)

**สิทธิ์:** เช็คอินสมาชิก รับชำระเงินหน้าร้านและบันทึกในระบบ ดูตารางจอง บล็อกสนาม เพิ่มสมาชิกใหม่

**การกำหนดสาขา:** Staff แต่ละคนผูกกับสาขาที่รับผิดชอบ ไม่สามารถเข้าถึงข้อมูลสาขาอื่นได้ ยกเว้น Admin เปิดสิทธิ์พิเศษ "หลายสาขา" ให้รายบุคคล

**ข้อมูลที่เข้าถึงได้:**
- ตารางจองของสาขาตัวเอง
- ข้อมูลสมาชิกพื้นฐาน (ชื่อ สถานะ วันหมด) เพื่อเช็คอิน
- ประวัติเช็คอินของสาขาตัวเอง
- บันทึกการรับชำระเงินหน้าร้านที่ตัวเองบันทึก

**ข้อมูล Staff Record:**

| Field | คำอธิบาย |
|---|---|
| staff_id | รหัสพนักงานไม่ซ้ำ |
| tenant_id | สนามเจ้าของ |
| name | ชื่อพนักงาน |
| email | อีเมลสำหรับ Login |
| phone | เบอร์โทร |
| branch_ids | สาขาที่รับผิดชอบ (array) |
| multi_branch_access | เข้าถึงข้ามสาขาได้ไหม |
| status | Active / Inactive |
| created_at | วันที่เพิ่มเข้าระบบ |

### 3.4 End User (ลูกค้า/สมาชิก)

**สิทธิ์:** จองสนาม แนบสลิปชำระเงิน ดูบัตรสมาชิกดิจิทัล เช็คอิน ดูประวัติการใช้งาน ต่ออายุสมาชิก Freeze/Unfreeze สมาชิก

**ข้อมูลที่เข้าถึงได้:** ข้อมูลตัวเองเท่านั้น (ประวัติการจอง ประวัติเช็คอิน สถานะสมาชิก)

## 4. Trial Period และ Onboarding

สนามสมัครบัญชีโดยไม่ต้องใส่บัตรเครดิต ได้รับสิทธิ์ทดลองใช้ Growth Plan ฟรี **14 วัน** ทันทีหลังสมัคร ระหว่าง Trial ใช้ฟีเจอร์ Growth ได้ครบทุกอย่าง รวมถึงรับชำระเงินจริงได้เลย

ก่อนหมด Trial **3 วัน** ระบบส่งแจ้งเตือนทาง Email และ LINE เมื่อครบ 14 วันถ้าไม่เลือกแพลน ระบบ Downgrade อัตโนมัติเป็น Free Plan ข้อมูลทั้งหมดยังอยู่ครบ แต่ฟีเจอร์จำกัด อัปเกรดได้ตลอดเวลาและฟีเจอร์กลับมาเต็มภายใน 5 นาที

**ข้อมูลที่เก็บระหว่าง Onboarding:**

| Field | คำอธิบาย |
|---|---|
| ชื่อสนาม/ฟิตเนส | ชื่อที่แสดงต่อลูกค้า |
| ชื่อเจ้าของ | ชื่อ-นามสกุล |
| เบอร์โทรศัพท์ | สำหรับติดต่อและแจ้งเตือน |
| อีเมล | Login + ใบเสร็จ Subscription |
| ที่อยู่สนาม | แสดงในโปรไฟล์สนาม |
| เบอร์/บัญชีพร้อมเพย์ | สำหรับรับชำระจากลูกค้า (QR PromptPay) |
| ประเภทธุรกิจ | สนามกีฬา / ฟิตเนส / ทั้งสอง |
| เลขประจำตัวผู้เสียภาษี | สำหรับออกใบเสร็จ (ไม่บังคับ) |
| การยินยอม PDPA | วันเวลาที่กดยอมรับ + IP Address |

## 6. PDPA — การคุ้มครองข้อมูลส่วนบุคคล

SportHub เก็บและประมวลผลข้อมูลส่วนบุคคลภายใต้ **พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562**

### 6.1 บทบาทตาม PDPA

**Data Controller — สนาม/ฟิตเนส (Tenant)**
สนามเป็นผู้กำหนดวัตถุประสงค์และวิธีการประมวลผลข้อมูลสมาชิก มีหน้าที่แจ้งนโยบายความเป็นส่วนตัวแก่สมาชิกและขอความยินยอม

**Data Processor — SportHub**
SportHub ประมวลผลข้อมูลตามคำสั่งของสนามเท่านั้น ไม่นำข้อมูลส่วนบุคคลของสมาชิกไปใช้เพื่อวัตถุประสงค์อื่น

### 6.2 จุดขอความยินยอม (Consent Points)

- **ลูกค้า/สมาชิก:** กดยืนยัน Checkbox "ฉันยอมรับนโยบายความเป็นส่วนตัว" ก่อนกรอกข้อมูลสมัครสมาชิกหรือทำการจองครั้งแรก ระบบบันทึกวันเวลาที่กดยินยอม
- **เจ้าของสนาม:** กดยืนยันการยินยอมระหว่าง Onboarding ก่อน Activate บัญชี ระบบบันทึกวันเวลาและ IP

### 6.3 ข้อมูลที่เก็บและวัตถุประสงค์

| ข้อมูล | วัตถุประสงค์ |
|---|---|
| ชื่อ-นามสกุล | ระบุตัวตน ออกใบเสร็จ |
| เบอร์โทร | แจ้งเตือน LINE ติดต่อ |
| อีเมล | ส่งใบเสร็จ แจ้งเตือน |
| วันเกิด | ตรวจสอบอายุ สิทธิ์พิเศษ |
| รูปโปรไฟล์ | บัตรสมาชิกดิจิทัล |
| ประวัติเช็คอิน | ติดตามการใช้งานตามสิทธิ์แพ็กเกจ |
| รูปสลิป | ยืนยันการชำระเงิน |
| ข้อมูลฉุกเฉิน | ติดต่อกรณีฉุกเฉินในสนาม |

### 6.4 นโยบายลบข้อมูลเมื่อสนามยกเลิกบัญชี

- สนามมีเวลา **30 วัน** หลังยกเลิกเพื่อ Export ข้อมูลทั้งหมด
- หลัง 30 วัน ระบบลบข้อมูลทั้งหมดของ Tenant นั้นถาวร (Hard Delete) รวมถึงข้อมูลสมาชิก รูปสลิป รูปโปรไฟล์
- Super Admin ดึงข้อมูลย้อนหลังได้ภายใน **7 วัน** หลัง Hard Delete (จาก Daily Backup)
- SportHub เก็บเฉพาะข้อมูลที่จำเป็นต่อการออกใบเสร็จ Subscription ตามกฎหมายบัญชี **(5 ปี)**

### 6.5 สิทธิ์ของเจ้าของข้อมูล (Data Subject Rights)

สมาชิก/ลูกค้าสามารถขอใช้สิทธิ์ผ่านหน้า **"จัดการข้อมูลส่วนตัว"** ในแอป หรือติดต่อสนามโดยตรง สนาม (Data Controller) ต้องตอบสนองคำขอทั้งหมดภายใน **30 วัน** ตามกฎหมาย

| สิทธิ์ | วิธีการ | ผู้ดำเนินการ |
|---|---|---|
| Right to Access | ขอดูข้อมูลส่วนตัวทั้งหมด ระบบส่งสรุปทาง Email | สมาชิกกดขอเองผ่านแอป |
| Right to Rectification | ขอแก้ไขข้อมูลที่ไม่ถูกต้อง | สมาชิกแก้ได้เอง (ชื่อ รูป เบอร์) ส่วนที่เกี่ยวกับแพ็กเกจ/สถานะ ต้องผ่าน Admin |
| Right to Erasure | ขอลบบัญชีและข้อมูลทั้งหมด | สมาชิกกด "ขอลบบัญชี" → Admin สนามยืนยัน → ดำเนินการภายใน 30 วัน |
| Right to Data Portability | ขอดาวน์โหลดข้อมูลตัวเองในรูปแบบ CSV | สมาชิกกด Export เองได้ทันที (ประวัติจอง ประวัติเช็คอิน ข้อมูลส่วนตัว) |
| Right to Object | ขอไม่รับ Broadcast/โปรโมชั่น | สมาชิก Opt-out ได้เองในหน้า Settings |
| Right to Restrict Processing | ขอระงับการใช้ข้อมูลชั่วคราว | แจ้งผ่านระบบหรือติดต่อสนามโดยตรง Admin ดำเนินการ |

### 6.6 Data Breach Notification

หากตรวจพบเหตุการณ์ข้อมูลรั่วไหล:
- SportHub แจ้ง **PDPC (สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล)** ภายใน **72 ชั่วโมง**
- แจ้ง Tenant ที่ได้รับผลกระทบโดยเร็วที่สุด พร้อมขอบเขตของข้อมูลที่รั่วไหล
- Tenant มีหน้าที่แจ้งเจ้าของข้อมูล (สมาชิก) เองหากการรั่วไหลมีความเสี่ยงสูงต่อสิทธิและเสรีภาพ

### 6.7 Data Residency

Supabase โฮสต์บน **AWS Singapore (ap-southeast-1)** ซึ่งถือเป็นการโอนข้อมูลส่วนบุคคลออกนอกราชอาณาจักร SportHub ต้อง:
- ระบุไว้ใน Privacy Policy และ Data Processing Agreement กับ Tenant ว่าข้อมูลประมวลผลที่สิงคโปร์
- AWS Singapore ได้รับการรับรองมาตรฐาน ISO 27001 / SOC 2 Type II ซึ่งถือว่ามีมาตรฐานคุ้มครองเพียงพอ

## 7. MODULE 1 — ระบบจองสนามกีฬา

### 7.1 ฝั่งลูกค้า

**ดูตารางสนามแบบ Realtime**
- แสดงตารางอัปเดตทันทีไม่ต้องรีเฟรช
- เห็นว่าช่วงไหนว่าง ถูกจอง หรือถูกบล็อก
- กรองตามประเภทสนาม วันที่ ราคา

*ข้อมูลที่แสดง:* ชื่อสนาม ประเภทสนาม ราคาต่อชั่วโมง (แยก Peak/Off-peak) ช่วงเวลาที่ว่าง/เต็ม/บล็อก

**ทำการจอง**
- เลือกสนาม วันเวลา กรอกข้อมูล ยืนยัน
- จองล่วงหน้าได้สูงสุดตาม **Advance Booking Limit** ที่ Admin ตั้งต่อสนาม (ค่าเริ่มต้น 30 วัน, ตั้งได้ 1–90 วัน)
- ระบบแสดง Policy การยกเลิกของสนามและให้ลูกค้ากด Checkbox ยอมรับก่อนยืนยัน

*ข้อมูลที่กรอก:* ชื่อผู้จอง เบอร์โทรศัพท์ หมายเหตุ (ถ้ามี)

**แจ้งเตือนก่อนถึงเวลาจอง**
- แจ้งเตือนผ่าน LINE อัตโนมัติก่อน **1 ชั่วโมง**

**ยกเลิกหรือเลื่อนการจอง**
- ยกเลิก/เลื่อนได้ตาม Cancellation Policy ของสนาม
- ระบบแสดง Policy ก่อนกดยืนยัน
- ถ้าอยู่ในช่วงที่ Policy อนุญาต ระบบดำเนินการอัตโนมัติ
- ถ้าเกินช่วงเวลา ปุ่มยกเลิกจะ Disabled และแสดงเหตุผล
- หมายเหตุ: การคืนเงิน PromptPay ต้องทำ Manual โดยสนาม

**ดูประวัติการจอง**

*ข้อมูลที่แสดง:* รหัสการจอง ชื่อสนาม วันเวลา ราคา สถานะ วันที่จอง ช่องทางชำระ

### 7.2 ฝั่ง Admin

**Dashboard รายได้และยอดจองแบบ Realtime**

## 8. MODULE 2 — ระบบสมาชิกฟิตเนส

### 8.1 ฝั่งสมาชิก

**สมัครสมาชิกออนไลน์**
- กรอกข้อมูล เลือกแพ็กเกจ ชำระเงิน รับบัตรดิจิทัลทันที

*ข้อมูลที่กรอกตอนสมัคร:* ชื่อ-นามสกุล เบอร์โทร อีเมล วันเกิด รูปโปรไฟล์ ข้อมูลสุขภาพเบื้องต้น (ถ้าสนามกำหนด) ชื่อและเบอร์ผู้ติดต่อฉุกเฉิน

**แพ็กเกจที่รองรับ**
- รายวัน รายสัปดาห์ รายเดือน 3 เดือน 6 เดือน รายปี แบบนับครั้ง (Admin สร้างได้เองไม่จำกัด)

**ดูสถานะสมาชิก**

*ข้อมูลที่แสดง:* ชื่อ เลขสมาชิก ประเภทแพ็กเกจ วันเริ่ม วันหมด เหลือกี่วัน จำนวนครั้งที่ใช้ไป/เหลือ (แพ็กเกจนับครั้ง) สาขาที่เข้าได้ สถานะ (Active / Expired / Frozen)

**ต่ออายุออนไลน์**
- ต่ออายุได้เองก่อนหมด เลือกแพ็กเกจใหม่หรือแพ็กเกจเดิม

**Renewal Reminder (แจ้งเตือนต่ออายุ)**
- ระบบส่งแจ้งเตือนผ่าน LINE ล่วงหน้า **7 วัน 3 วัน และวันหมดอายุ**
- แจ้งเตือนพร้อม Link ต่ออายุและ QR PromptPay ของสนาม
- **หมายเหตุสำคัญ:** ระบบนี้คือ "แจ้งเตือนให้โอนเงิน" เท่านั้น ไม่ได้หักเงินอัตโนมัติ สมาชิกต้องโอนเองและแนบสลิปทุกครั้ง

**Freeze สมาชิก**
- ระงับสมาชิกชั่วคราวกรณีบาดเจ็บหรือเดินทาง วันที่ Freeze ไม่นับรวมในอายุ
- **ขอบเขต Default:** Freeze ได้สูงสุด **30 วัน** ต่อรอบแพ็กเกจ และสูงสุด **2 ครั้ง** ต่อแพ็กเกจ (Admin ปรับค่าได้ต่อแพ็กเกจ)
- สมาชิกกด Freeze เองได้ → Admin ยืนยัน (หรือตั้งให้ Approve อัตโนมัติ)
- สมาชิกกด Unfreeze ได้เองเมื่อพร้อม

**ดูประวัติเข้าใช้งาน**

*ข้อมูลที่แสดง:* วันเวลาเช็คอิน สาขา วิธีเช็คอิน (QR / Staff) จำนวนครั้งรวมทั้งหมด

## 9. MODULE 3 — ระบบชำระเงิน (ลูกค้า → สนาม)

### 9.1 ช่องทาง: QR PromptPay + แนบสลิป

ไม่มี Payment Gateway ไม่มีบัตรเครดิต ไม่มีค่าธรรมเนียมรายธุรกรรม เงินโอนตรงเข้าบัญชีสนามทันที SportHub ไม่ได้แตะเงินส่วนนี้

### 9.2 Flow การชำระเงิน

1. ลูกค้าเลือกสนามหรือแพ็กเกจ กดยืนยัน
2. ระบบแสดง QR PromptPay ของสนามพร้อมยอดเงิน
3. ลูกค้าเปิดแอปธนาคารสแกน QR โอนเงิน
4. ลูกค้าแนบสลิปในหน้าเดียวกัน
5. ระบบเปลี่ยนสถานะเป็น **"รอยืนยัน"** และล็อก Slot ไว้ **30 นาที**
6. Admin เห็นสลิปใหม่ใน Dashboard กดยืนยันหรือปฏิเสธ
7. ลูกค้าได้รับแจ้งเตือนผ่าน LINE ว่าการจองยืนยันแล้ว พร้อม QR เช็คอิน

### 9.3 สถานะการจอง

| สถานะ | ความหมาย |
|---|---|
| รอชำระ | จองแล้วยังไม่แนบสลิป หมด 30 นาทียกเลิกอัตโนมัติ |
| รอยืนยัน | แนบสลิปแล้ว รอ Admin กดยืนยัน |
| ยืนยันแล้ว | การจองสมบูรณ์ |
| ปฏิเสธ | Admin ปฏิเสธสลิป แจ้งเหตุผล สนามปล่อยว่างกลับ |
| รอคืนเงิน | Admin ปฏิเสธสลิปและยังไม่ได้โอนเงินคืน |
| คืนเงินแล้ว | Admin ยืนยันว่าโอนคืนเรียบร้อย |
| ยกเลิก | ลูกค้ายกเลิกเองหรือหมดเวลา 30 นาที |

### 9.4 กระบวนการเมื่อ Admin ปฏิเสธสลิป

เนื่องจาก PromptPay เป็น P2P ระบบไม่สามารถคืนเงินอัตโนมัติได้ ใช้ขั้นตอนดังนี้:

**ฝั่ง Admin:**
1. กดปฏิเสธ ระบุเหตุผล (เช่น ยอดไม่ตรง / สลิปไม่ชัด / ชื่อผู้โอนไม่ตรง / สลิปซ้ำ)
2. ระบบเปลี่ยนสถานะเป็น "รอคืนเงิน" และแสดงใน **Pending Refund List**
3. Admin โอนเงินคืนให้ลูกค้าเองผ่านแอปธนาคารภายใน 24 ชั่วโมง
4. Admin กดยืนยัน "โอนคืนแล้ว" และแนบหลักฐาน
5. สถานะเปลี่ยนเป็น "คืนเงินแล้ว"

**ฝั่งลูกค้า:**
1. ได้รับแจ้งเตือน LINE ว่าสลิปถูกปฏิเสธพร้อมเหตุผล
2. ระบบแสดงข้อความ "สนามจะโอนเงินคืนภายใน 24 ชั่วโมง กรุณาติดต่อสนามหากไม่ได้รับ"
3. เห็นสถานะ "รอคืนเงิน" ในประวัติการจอง
4. เมื่อสนามโอนคืนแล้ว สถานะเปลี่ยนเป็น "คืนเงินแล้ว" พร้อมแจ้งเตือน LINE

### 9.5 ป้องกันสลิปซ้ำ (Duplicate Slip Detection)

ระบบตรวจจับสลิปซ้ำโดยเปรียบเทียบ: วันเวลาในสลิป + ยอดเงิน + ชื่อผู้โอน หากตรวจพบสลิปที่ใกล้เคียงกับที่มีอยู่แล้วในระบบ (ภายใน Tenant เดียวกัน) ระบบแจ้งเตือน Admin ให้ตรวจสอบก่อนยืนยัน Admin ยังสามารถยืนยันหรือปฏิเสธได้ตามดุลยพินิจ

- ดูรูปสลิปขยายได้

## 11. MODULE 5 — ระบบ Subscription สนาม (B2B Payment — Omise)

### 11.1 ภาพรวม

SportHub เก็บค่า Subscription รายเดือนจากสนาม/ฟิตเนสผ่าน **Omise Payment Gateway** รองรับ:
- บัตรเครดิต/เดบิต (Visa / Mastercard)
- Internet Banking
- PromptPay (สำหรับสนามที่ต้องการชำระเอง)

### 11.2 Flow การชำระ Subscription

**ครั้งแรก (หลัง Trial):**
1. ก่อนหมด Trial 3 วัน ระบบส่ง Email + LINE แจ้งเตือนให้เลือกแพลน
2. Admin สนามเลือกแพลน กรอกข้อมูลการชำระ (บัตรหรือ PromptPay)
3. Omise เก็บเงินรอบแรก
4. บัญชีอัปเกรดทันที ได้รับใบเสร็จอัตโนมัติทาง Email

**รอบถัดไป (รายเดือน):**
1. ถ้าผูกบัตร → Omise ตัดบัตรอัตโนมัติทุกเดือน
2. ถ้าชำระด้วย PromptPay → ระบบส่ง Invoice + QR PromptPay ของ SportHub ทุกต้นเดือน
3. ได้รับใบเสร็จอัตโนมัติหลังชำระสำเร็จ

**กรณีชำระไม่สำเร็จ:**
1. ระบบส่งแจ้งเตือนทาง Email + LINE ทันที
2. มี **Grace Period 3 วัน**
3. หากเกิน Grace Period → ระบบ Downgrade เป็น Free Plan อัตโนมัติ ข้อมูลทั้งหมดยังอยู่ครบ
4. เมื่อชำระสำเร็จ → บัญชีกลับสู่แพลนเดิมภายใน 5 นาที

### 11.3 Invoice และใบเสร็จ Subscription

**หมายเหตุ VAT:** Invoice ระบุ VAT 7% ดังนั้น SportHub ต้องจดทะเบียนภาษีมูลค่าเพิ่ม (เกณฑ์รายได้เกิน 1.8 ล้านบาท/ปี หรือจดก่อนได้) ก่อนเริ่มเก็บ Subscription จริง

### 11.4 การ Upgrade / Downgrade แผนกลางรอบ

**Upgrade (Growth → Pro):**
- ชำระเพิ่มเฉพาะส่วนต่างตามจำนวนวันที่เหลือในรอบนั้น (Pro-rata คำนวณรายวัน)
- ตัวอย่าง: เหลือ 15 วันจาก 30 วัน ชำระเพิ่ม = (1,499 − 899) × 15/30 = **300 บาท**
- คิดผ่าน Omise ทันที ฟีเจอร์ Pro เปิดทันทีหลังชำระสำเร็จ
- วันครบรอบถัดไปคิดราคา Pro เต็ม 1,499 บาท

**Downgrade (Pro → Growth):**
- มีผลตั้งแต่รอบถัดไป ไม่มีการคืนเงินสำหรับรอบที่ชำระแล้ว
- ยังใช้ฟีเจอร์ Pro ได้ครบจนหมดรอบปัจจุบัน

### 11.5 นโยบายคืนเงิน Subscription

- ไม่มีการคืนเงินสำหรับรอบที่ชำระแล้วและใช้งานไปแล้ว
- กรณียกเลิก Subscription ก่อนหมดรอบ ยังใช้งานได้จนหมดรอบที่จ่ายไว้ จะไม่เรียกเก็บรอบถัดไป
- กรณีระบบ SportHub Down เกิน **24 ชั่วโมงต่อเนื่อง** พิจารณาคืนเงินตามสัดส่วน (Case by case โดย Super Admin อนุมัติผ่าน Omise Refund)

## 17. Tech Stack

**Backend — Supabase Pro ($25/เดือน)**
- Database PostgreSQL รองรับ Multi-tenant ด้วย Row Level Security
- Auth สำหรับสมาชิกฟิตเนสและ Staff
- Storage เก็บรูปสลิป รูปโปรไฟล์ รูปสนาม
- Realtime สำหรับอัปเดตตาราง สถานะสลิป และ Occupancy

**Frontend — Next.js**
- Performance สูงและ Custom ได้เต็มที่
- Hosting: Vercel Pro (~$20/เดือน)

**การแจ้งเตือน — LINE Messaging API**
- แจ้งเตือนการจอง ยืนยันสลิป Renewal Reminder คำเตือน Trial
- ฟรีถึง 500 ข้อความ/เดือน/channel หลังจากนั้น ~0.15 บาท/ข้อความ

**Email — SendGrid**
- ส่งใบเสร็จ ยืนยันการสมัคร แจ้งเตือน Trial Invoice Subscription
- Free tier 100 ฉบับ/วัน: 0 บาท/เดือน

**Payment B2B — Omise**
- เก็บค่า Subscription รายเดือนจากสนาม
- ค่าธรรมเนียม: 3.65% + 10 บาท/รายการ (บัตรเครดิต) หรือ 0.5% (PromptPay)
- ไม่มีค่ารายเดือนคงที่
- ข้อมูลบัตรจัดการโดย Omise โดยตรง (PCI-DSS Compliant) SportHub ไม่เก็บเลขบัตร

**QR Generator — สร้างในระบบ**
- ใช้ Library มาตรฐานสร้าง QR PromptPay และ QR บัตรสมาชิก
- ไม่มีค่าใช้จ่ายเพิ่ม

## 19. Roadmap

**เฟส 1 เดือนที่ 1–2 เตรียมระบบ**
เรียน Supabase และ Next.js ออกแบบ Database Schema รองรับ Multi-tenant ตั้งค่า Row Level Security สร้าง Auth และ Onboarding Flow ตั้งค่า Omise และ LINE Messaging API ร่าง Privacy Policy และ Data Processing Agreement

Module 1 จองสนามครบ + Module 3 QR PromptPay + สลิปครบ + Module 5 ระบบ Subscription Omise ทดสอบ Flow จนไม่มีบัค

**เฟส 3 เดือนที่ 3–4 เพิ่ม Fitness**

**เฟส 4 เดือนที่ 4–5 Launch**
เปิด Trial ให้สนามสมัครได้ทั่วไทย เริ่มเก็บ Subscription (จด VAT ก่อนถ้ายังไม่ได้จด) ยิง TikTok/Facebook Ad เพิ่มฟีเจอร์ตาม Feedback

## 32. Offboarding Flow — เมื่อสนามยกเลิกบัญชี

**ขั้นตอนเมื่อสนามแจ้งยกเลิก:**
1. Admin สนามกดยกเลิกบัญชีใน Settings
2. ระบบยืนยันด้วย Email OTP
3. บัญชีเข้าสู่ระยะ "ยกเลิกแล้วรอลบ" ทันที
4. ฟีเจอร์ทั้งหมดปิดลง แต่ยังดาวน์โหลดข้อมูลได้ 30 วัน
5. Super Admin ได้รับแจ้งเตือนว่ามี Tenant ยกเลิก
6. Omise หยุดเก็บเงินรอบถัดไปทันที

**การจัดการ Active Booking เมื่อสนามยกเลิก:**
- ระบบตรวจสอบ Booking ที่สถานะ "ยืนยันแล้ว" ซึ่งยังไม่ถึงเวลา
- ส่ง LINE + Email แจ้งลูกค้าทุกรายว่าสนามหยุดให้บริการบนระบบ พร้อมเบอร์ติดต่อสนามโดยตรง
- สนามต้องรับผิดชอบประสานงานคืนเงินหรือเลื่อนจองกับลูกค้าเอง SportHub ไม่รับผิดชอบส่วนนี้
- ข้อความแจ้งลูกค้า: "สนาม [ชื่อ] หยุดให้บริการบน SportHub กรุณาติดต่อสนามโดยตรงที่เบอร์ [xxx] เพื่อเลื่อนหรือขอคืนเงิน"

**การแจ้งสมาชิกฟิตเนส:**
- สมาชิกที่ Active ทุกรายได้รับแจ้งทาง LINE ว่าสนามหยุดให้บริการบนระบบ
- แสดงข้อมูล: วันที่หมดบริการ เบอร์ติดต่อสนาม คำแนะนำให้ดาวน์โหลดข้อมูลส่วนตัว
- สมาชิกดาวน์โหลดประวัติเช็คอินและข้อมูลส่วนตัวได้ 30 วัน

**ช่วง 30 วัน Grace Period หลังยกเลิก:**
- สนามยังเข้าระบบได้ในโหมด Read-only
- ดาวน์โหลดข้อมูลได้ทั้งหมด (สมาชิก การจอง ประวัติ รายงาน) ในรูปแบบ CSV/Excel
- ยกเลิกการยกเลิก (Reactivate) ได้ภายใน 30 วัน

**หลัง 30 วัน:**
- ระบบลบข้อมูล Tenant ถาวรทั้งหมด (Hard Delete)
- รวมถึงข้อมูลสมาชิก ประวัติเช็คอิน รูปสลิป รูปโปรไฟล์
- ยกเว้น: ข้อมูลใบเสร็จ Subscription ที่ SportHub เก็บตามกฎหมายบัญชี (5 ปี)
- SportHub ส่ง Email ยืนยันการลบข้อมูลให้สนาม

**กรณีถูก Suspend (ค้างชำระ / ละเมิดข้อตกลง):**
1. Super Admin ระงับบัญชีสนาม
2. สนามยังเข้า Dashboard ได้ในโหมด Read-Only
3. มีเวลา **14 วัน** ในการชำระค้างหรือแก้ไขปัญหา
4. หากไม่ดำเนินการภายใน 14 วัน เข้าสู่ขั้นตอนเดียวกับการยกเลิกเอง

**Super Admin:**
- ดึงข้อมูลย้อนหลังได้ภายใน 7 วันหลัง Hard Delete (จาก Daily Backup)

```
→ อ่านและยอมรับ Cancellation Policy
→ กรอกชื่อ + เบอร์
→ [QR PromptPay แสดง + นับถอยหลัง 30 นาที]
→ เปิดแอปธนาคาร สแกน QR โอนเงิน
→ อัปโหลดสลิป
→ สถานะ: รอยืนยัน
   ├── [Admin ยืนยัน] → LINE: "จองสำเร็จ พร้อม QR เช็คอิน"
   ├── [Admin ปฏิเสธ] → LINE: "สลิปถูกปฏิเสธ [เหตุผล] รอคืนเงินภายใน 24 ชม."
   └── [หมดเวลา 30 นาที] → ยกเลิกอัตโนมัติ → LINE: "การจองหมดเวลา"
```

### 34.2 Member Registration Flow (ลูกค้า)

```
เข้าหน้าสมัครสมาชิก
→ กรอกข้อมูลส่วนตัว + ผู้ติดต่อฉุกเฉิน
→ เลือกแพ็กเกจ
→ อ่านและกด Checkbox ยินยอม PDPA
→ [QR PromptPay แสดง]
→ โอนเงิน + อัปโหลดสลิป
   ├── [Admin ยืนยัน] → รับบัตรสมาชิกดิจิทัลทันที + LINE ยืนยัน
   └── [Admin ปฏิเสธ] → LINE: "[เหตุผล] รอคืนเงินภายใน 24 ชม."
```

### 34.3 Check-in Flow (สมาชิก)

```
เปิดแอป → บัตรสมาชิก
→ [Growth: QR Static] หรือ [Pro: QR Dynamic รีเฟรชทุก 30 วิ]
→ Staff / Kiosk สแกน QR
→ ระบบตรวจสอบ < 1 วินาที
   ├── ✅ ผ่าน → แสดง "ยินดีต้อนรับ [ชื่อ] [แพ็กเกจ]"
   │           → Occupancy เพิ่ม 1
   │           → Auto Check-out หลัง avg_session_duration
   │              หรือ Scan-out (Pro)
   │           → Occupancy ลด 1
   └── ❌ ไม่ผ่าน → แสดงเหตุผล
                  (หมดอายุ / Frozen / ไม่มีสิทธิ์สาขา / ครบครั้ง / สาขาเต็ม)
```

### 34.4 Trial → Paid Subscription Flow (สนาม)

```
สมัครบัญชีใหม่
→ ยอมรับ ToS + DPA + PDPA → กรอก Onboarding Data
→ เริ่ม Trial 14 วัน (Growth Plan ฟรีเต็มรูปแบบ)
→ [Day 11] Email + LINE: "Trial เหลือ 3 วัน เลือกแพลนเพื่อใช้งานต่อ"
→ [Day 14]
   ├── [เลือกแพลน] → หน้า Growth/Pro → Omise Payment → ชำระสำเร็จ → Activate ทันที
   └── [ไม่เลือก] → Downgrade เป็น Free Plan อัตโนมัติ
                  → Banner "อัปเกรดเพื่อใช้งานครบฟีเจอร์"
                  → Admin กดอัปเกรดได้ตลอดเวลา → ฟีเจอร์กลับมาภายใน 5 นาที
```

### 34.5 Refund Flow

```
Admin ปฏิเสธสลิป → ระบุเหตุผล
→ สถานะ: รอคืนเงิน → ขึ้น Pending Refund List
→ LINE แจ้งลูกค้า: "สลิปถูกปฏิเสธ [เหตุผล] สนามจะโอนคืนภายใน 24 ชม."
→ Admin โอนเงินคืนผ่าน PromptPay เอง
→ Admin กด "ยืนยันคืนเงินแล้ว" + แนบหลักฐาน
→ สถานะ: คืนเงินแล้ว → LINE แจ้งลูกค้า
→ Slot สนามกลับมาว่าง
```

### 34.6 Freeze / Unfreeze Flow

```
สมาชิกกด "ขอ Freeze" → ระบุเหตุผล
→ [Auto-Approve ON]  → Frozen ทันที → วันหมดอายุถูกยืดออก → LINE ยืนยัน
→ [Auto-Approve OFF] → Admin เห็นคำขอ
                      ├── Approve → Frozen → LINE ยืนยัน
                      └── Reject  → LINE แจ้งเหตุผล

[ระหว่าง Frozen]
→ เช็คอินไม่ผ่าน แสดง "สมาชิกถูกระงับชั่วคราว"
→ สมาชิก Unfreeze เองได้ หรือหมดวันที่ Freeze → Active อัตโนมัติ
→ นับ freeze_days_used สะสม
```

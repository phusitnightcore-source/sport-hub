# Organizer Membership — Deployment & UAT

ระบบนี้กำหนดให้ผู้สร้างก๊วนหรือทัวร์นาเมนต์ต้องเป็นเจ้าของสนาม หรือเป็นผู้ใช้ที่มีแพ็กเกจรายเดือนที่ยังไม่หมดอายุ

## สิทธิ์และราคาเริ่มต้น

- เจ้าของสนาม: จัดก๊วนและทัวร์นาเมนต์ได้โดยอัตโนมัติ พร้อมแบจ `เจ้าของสนาม`
- ผู้จัดก๊วน — 149 บาท/เดือน: สร้างก๊วนชุมชนและบริหารสมาชิก พร้อมแบจ `ผู้จัดก๊วน`
- ผู้จัดทัวร์นาเมนต์ — 299 บาท/เดือน: สร้างรายการ จัดสาย ตรวจสมัคร/ชำระเงิน เช็กอิน และบันทึกผล พร้อมแบจ `ผู้จัดการแข่งขัน`
- Organizer Pro — 399 บาท/เดือน: ได้สิทธิ์ทั้งสองระบบ พร้อมแบจ `Organizer Pro`
- โค้ชที่อนุมัติแล้วแสดงแบจ `โค้ชยืนยันแล้ว` แยกจากสิทธิ์ผู้จัด

แก้ราคา ชื่อ หรือเปิด/ปิดแพ็กเกจได้โดยอัปเดตตาราง `organizer_plans` โดยไม่ต้องแก้หน้าเว็บ

## ขั้นนำขึ้นฐานข้อมูล

1. เปิด Supabase SQL Editor ของ production
2. รันไฟล์ `supabase/migrations/20260929010000_organizer_memberships.sql` ทั้งไฟล์หนึ่งครั้ง
3. ตรวจว่าเกิดตาราง `organizer_plans`, `organizer_subscriptions`, `organizer_subscription_orders`
4. ตรวจว่า Storage มี bucket ส่วนตัวชื่อ `organizer-slips`
5. Deploy เว็บหลัง migration สำเร็จ เพื่อไม่ให้หน้า Organizer เรียกตารางที่ยังไม่มี

Migration นี้ยังปิดสิทธิ์เขียนแบบกว้างของระบบก๊วน/ทัวร์นาเมนต์เดิม และบังคับตรวจทั้งเจ้าของข้อมูลกับวันหมดอายุแพ็กเกจที่ฐานข้อมูล

## Environment

ตั้งค่า `SPORTHUB_PROMPTPAY_ID` เป็นเบอร์โทรศัพท์หรือเลขพร้อมเพย์ที่ต้องการแสดงในหน้าชำระแพ็กเกจ และคงค่า Supabase ฝั่ง server ตาม `.env.example` ให้ครบ

## โฟลว์ใช้งาน

1. ผู้ใช้เปิด `/me/organizer` เลือกแพ็กเกจและแนบสลิป
2. รายการอยู่สถานะ `awaiting_verification`; ผู้ใช้ส่งรายการรอตรวจได้ครั้งละหนึ่งรายการ
3. Super Admin เปิด `/super-admin/organizers`, ดูหลักฐานผ่านลิงก์ชั่วคราว แล้วอนุมัติหรือปฏิเสธ
4. เมื่ออนุมัติ ฐานข้อมูลเปิดสิทธิ์หนึ่งเดือนแบบ atomic; การต่ออายุจะนับต่อจากวันหมดอายุเดิม
5. ผู้ใช้เห็นแบจหลังชื่อใน Player Hub, หน้าก๊วน และหน้ารวมทัวร์นาเมนต์
6. เมื่อหมดอายุ ระบบหยุดสิทธิ์สร้าง/แก้ไขทันที แต่ข้อมูลเดิมยังไม่ถูกลบ

## UAT ก่อนเปิดจริง

- เจ้าของสนามเข้า Organizer Hub และจัดก๊วน/ทัวร์นาเมนต์ได้โดยไม่ซื้อแพ็กเกจ
- ผู้ใช้ทั่วไปยังสร้างก๊วนหรือทัวร์นาเมนต์ไม่ได้ และเห็นปุ่มสมัคร
- ส่งสลิป JPG/PNG/WebP ไม่เกิน 4 MB ได้; ไฟล์อื่นถูกปฏิเสธ
- Super Admin เปิดดูสลิป อนุมัติ และปฏิเสธได้
- กดอนุมัติซ้ำหรือพร้อมกันไม่ทำให้วันหมดอายุเพิ่มซ้ำ
- แพ็กเกจผู้จัดก๊วนเข้าได้เฉพาะก๊วน; แพ็กเกจทัวร์นาเมนต์เข้าได้เฉพาะการแข่งขัน; Pro เข้าได้ทั้งคู่
- ผู้จัดแก้ไขได้เฉพาะรายการที่ตนสร้าง
- แพ็กเกจหมดอายุแล้ว Server Action และ RLS ปฏิเสธการจัดการ
- Staff ทั่วไปเปิดหน้าจัดการก๊วนทางการและหน้าทัวร์นาเมนต์ของเจ้าของสนามไม่ได้
- ทดสอบทั้ง Light/Dark บนมือถือและเดสก์ท็อป

## Rollback เชิงธุรกิจ

หากต้องหยุดขายชั่วคราว ให้ตั้ง `organizer_plans.is_active = false` เฉพาะแพ็กเกจที่ต้องการ ระบบจะหยุดขายและหยุด entitlement ของแพ็กเกจนั้นทันทีโดยไม่ลบประวัติคำสั่งซื้อ
